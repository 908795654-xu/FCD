# GitHub distribution

This upload copy contains model code, experiment scripts, environment snapshots,
reference results and reproducibility documentation. Manuscript drafts, internal
ZIP archives, datasets and pretrained model weights are not distributed here.

The working repository remains unchanged. Historical paths and fingerprints inside
recorded results remain metadata; they are not rewritten as new runs. Reference
metrics are preserved byte-for-byte. A file manifest is provided for this copy.

The repository is initially private. FCD contributions use Apache-2.0; third-party
components retain their own terms. LGA and the unconfirmed legacy pollution tool
are externally obtained, not bundled. Some historical
recipe/figure attribution limitations are documented in the reproducibility notes.
